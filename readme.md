# Función
Sistema de inventario de productos, registra un producto lo  cual solicita; nombre y cantidad, los cuales se visualizan en la interfaz principal los productos registrados y disponibilidad.


# Tecnologías
PHP 8.2
MariaDB 10.4
CSS
Un servidor local(XAMPP)


# Necesita Instalar
Xampp 3.3 [Inlcuye servidor y php]
Visual Studio Code 1.138 (Opcional)
Navegador web(Egde 153.0)
Gestor de BD(Heidi 12.15)



# Configuracion y Ejecucion
*Copiar proyecto
*Guardarlo en la ruta local del servidor
*Crear BD
*Configurar credenciales
*Verificar conexiones
*Ejecutar el script
*Abrirla desde un navegador web
*Colocar la direccion web
